# Completion audit for the Rust migration

The objective is the full installed Python application's behavior plus faster
GPU execution and efficient small previews. This checklist preserves that scope;
a green unit suite alone does not prove the migration complete.

Reference: adjacent Python v0.3.4, commit
`3bb2c2d2801ff68b92019cf1dbcbb133d60832bc`.

## Reproduce the stricter GPU audit

```sh
cargo run --release -p spektrafilm-cli --features precision-f64 \
  --example gpu_accuracy -- /tmp/spektrafilm-gpu-accuracy.json
```

The audit records failures instead of silently relaxing the tolerance. Its
synthetic image includes out-of-range linear light and unsharp overshoot; these
must stay finite and match the reference rather than being hidden by clipping.
